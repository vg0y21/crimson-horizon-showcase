# Crimson Horizon — images and video showcase

This repository is intended to contain only the public marketing page, screenshots and a link to the already-published promotional video. It must NOT contain the purchasable template, delivery ZIP, customer data or payment credentials.

## Publish

Create a new, empty public repository (with no source-template Git history), upload this folder, then select Settings → Pages → Deploy from a branch → main → /(root).

The original `vg0y21/crimson-Horizon` repository must become private separately to stop public access to its source and commit history. Merely deleting files, replacing the home page, or creating this gallery inside that repository does not hide previous commits. Copies already downloaded cannot be revoked.

Making the original repository private may stop its GitHub Pages site on a free GitHub plan. Publish this clean showcase first and use its new URL for visitors. Keep the original source repository for private development and prepare customer deliverables outside this public repository.

## Media

Screenshots are supplied by Yaser. The video is the approved 25.5-second Bilal-narrated advertisement, already published by Yaser on Instagram and TikTok. The HTML video uses the existing Metricool-hosted MP4, with the published Instagram Reel provided as a fallback. The video host is external; replace the MP4 URL if that host becomes unavailable.

The only JavaScript here opens screenshot previews. No iframe, template demo, payment processor or product download is included. Contact and order buttons link to Yaser's Instagram profile, and do not claim online payment is activated.

No browser-side DRM is claimed. Public screenshots and the marketing page can be copied. Protection depends on keeping the actual product files and their Git history private.
